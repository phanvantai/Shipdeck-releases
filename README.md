# Shipdeck releases

Notarized builds of [Shipdeck](https://github.com/phanvantai/Shipdeck-releases/releases), a native macOS control center for a portfolio of apps, games and websites built with Claude Code agents.

- **Download:** the latest zip from [Releases](https://github.com/phanvantai/Shipdeck-releases/releases/latest). Unzip and move `Shipdeck.app` to Applications. It requires macOS 15 or later.
- **Updates:** Shipdeck checks `appcast.xml` in this repo once a day and offers new versions in the app. Each update is signed, and Shipdeck verifies the signature before installing.

The source code is private. This repo only holds release builds and the update feed.
